# 🧮 Calculadora em Python com Kivy

Calculadora com **interface gráfica** desenvolvida em **Python** usando o framework **Kivy**, durante o curso **Linguagem de Programação Python**, da **Fundação Bradesco**.

O projeto aplica os conceitos básicos da linguagem em um aplicativo com janela e botões, em vez de rodar apenas no terminal.

## 📂 Estrutura do repositório

```
Calculadora/
├── Calculadora Simples/   # Código da calculadora
├── .gitattributes
└── README.md
```

## ✨ Funcionalidades

- Interface gráfica com botões numéricos e de operações
- Operações matemáticas básicas (soma, subtração, multiplicação e divisão)
- Exibição do resultado na tela

> Ajuste esta lista conforme o que a sua calculadora realmente faz.

## 🛠️ Tecnologias

- [Python 3](https://www.python.org/)
- [Kivy](https://kivy.org/), framework para criação de interfaces gráficas
- Git e GitHub

## ▶️ Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/Thuliofj/Calculadora.git
   ```

2. Instale o Kivy:

   ```bash
   pip install kivy
   ```

3. Entre na pasta do projeto:

   ```bash
   cd "Calculadora/Calculadora Simples"
   ```

4. Execute o arquivo principal:

   ```bash
   python nome_do_arquivo.py
   ```

> Substitua `nome_do_arquivo.py` pelo nome real do arquivo dentro da pasta.
